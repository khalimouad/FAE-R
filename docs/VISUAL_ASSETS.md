Photography is illustrative stock from Unsplash, not FAE-R staff, facilities, inventory or training sessions.

Source photos:

Images use fixed aspect ratios, responsive hero sources and lazy loading below the fold. Remote image service availability is required.

The inline first-aid kit and card icons are original SVG artwork created for this site. They do not represent an approved company logo or certification.

Motion uses native IntersectionObserver and Web Animations APIs with cleanup. Content is visible without those APIs. Reduced-motion settings skip scroll reveals, entrance effects and illustration movement. Hero artwork floats for two cycles only. A scroll progress line is enabled where CSS scroll timelines are supported.
